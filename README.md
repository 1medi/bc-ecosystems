# Library of the Ecosystems of British Columbia

# 🌲 BC Ecosystems Explorer

**Explore the rich biodiversity of British Columbia through an interactive and educational web experience.**

## 🔍 Overview

BC Ecosystems Explorer is a responsive, animated web app designed to educate users about the diverse biogeoclimatic zones of British Columbia. From Coastal Western Hemlock forests to the dry grasslands of the Bunchgrass zone, the app helps users explore climate data, vegetation types, wildlife, and Indigenous knowledge — all through dynamic visuals and intuitive navigation.

## 🚀 Features

* 🌐 **Interactive Map Navigation**
  Explore BC's zones via a clickable ecosystem selector.

* 📸 **Responsive Image Galleries**
  Each ecosystem page includes visual highlights with hover overlays and photo galleries.

* 📊 **Climate and Species Charts**
  Custom-built Recharts graphs present climate data and dominant vegetation species.

* 🧾 **Land Acknowledgement**
  Acknowledges Indigenous territories across BC with animated text and region-specific slides.

* 💻 **Performance Optimized**
  Webp images an layout structures for mobile and desktop.

## 🧱 Tech Stack

* **Frontend:** React, Tailwind CSS, Framer Motion
* **Routing:** React Router + HashLink
* **Data Visualization:** Recharts
* **Other Tools:** Git, Figma (for design), Vite (for development)


## 🗺️ Ecosystems Included

* Coastal (CDF, CWH, MH)
* Southern Interior (BG, PP)
* Central Interior (ICH, IDF, MS, SBPS, SBS)
* Northern BC (BWBS, SWB, ESSF)
* Alpine Tundra (IMA/CMA/BAFA)
